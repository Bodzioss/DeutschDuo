# Deutsch Duo — Etap 0 + 1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instalowalna PWA dla dwóch profili (Nikola, Marcin) z ~600 słowami A1, fiszkami FSRS, panelem „Heute”, streakiem z zamrożeniem, statystykami, offline-first z synchronizacją do Supabase.

**Architecture:** Czysta logika domenowa w `src/domain` (bez React, bez IO, w pełni testowana Vitestem). Dane lokalne w Dexie, osobna baza na profil; Supabase jako źródło prawdy przez wąski interfejs `SyncBackend` (implementacja Supabase + implementacja fake do testów/E2E). UI w React per feature, stan w Zustand.

**Tech Stack:** React 18, TypeScript (strict), Vite, vite-plugin-pwa, Tailwind CSS 3, Zustand, Dexie 4, ts-fsrs, React Router 6, @supabase/supabase-js 2, Vitest + fake-indexeddb, Playwright, tsx (skrypty).

**Spec:** `docs/superpowers/specs/2026-11-15-etap-0-1-mvp-design.md` (oraz tło: `docs/SPEC.md`).

## Global Constraints

- Mobile-first: każdy ekran projektowany i sprawdzany przy 375×812; brak poziomego scrolla.
- Offline-first: każdy zapis najpierw do Dexie; sieć nigdy nie blokuje sesji.
- Start sesji < 2 s przy ponownym uruchomieniu (precache PWA całej aplikacji i słów).
- Kolory rodzajów wszędzie: der = niebieski, die = czerwony, das = zielony (tokeny Tailwind `der`, `die`, `das`, z wariantami dla trybu ciemnego).
- Tryb ciemny: wg systemu + przełącznik w ustawieniach (`class` strategy Tailwind).
- Język UI: polski. Język pomostowy kart: EN (+PL opcjonalnie, `show_pl`).
- Granica doby: 03:00 czasu lokalnego urządzenia.
- FSRS: `request_retention = 0.9`, pozostałe parametry domyślne `ts-fsrs`.
- Limity sesji: max 150 powtórek dziennie; nowe słowa domyślnie 10 (zakres 5–20); cel dzienny domyślnie 15 min.
- Streak: +1 zamrożenie za każde 7 dni streaka, max 2 w zapasie.
- Statusy: nowe (brak ocen) / uczę się (stabilność < 7) / znam (7–30) / opanowane (> 30), wg max stabilności z obu kart słowa.
- Sekrety: w kliencie tylko `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_PAIR_EMAIL`. Nigdy service key.
- Zrzut Wiktextract nie trafia do repo (`.gitignore`); pobranie wymaga zgody Marcina w momencie wykonania.
- Atrybucja CC BY-SA (Wiktionary/Wiktextract) na ekranie „O danych”.
- Commity kończą się linią `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Decyzja planu (uzupełnia spec §5.3):** cel dzienny „ukończenie kolejki” nie wynika z samych ocen, więc `ReviewRecord` dostaje pole `closesQueue: boolean` — `true` na recenzji, która opróżniła dzisiejszą kolejkę. Dzięki temu streak dalej wylicza się wyłącznie z `reviews`.

## Review Focus

1. **Pierwsza recenzja po północy, a przed 3:00** — liczy się do poprzedniego dnia; streak nie może się wyzerować ani „podwoić”. → test w Task 4 (`localDay` 02:59 vs 03:00) i Task 4 (`computeStreak` z recenzją o 01:30).
2. **Powrót po długiej przerwie (np. 10 dni, 400 zaległych kart)** — sesja ma ≤ 150 powtórek, streak poprawnie zużywa zamrożenia i potem zeruje, aplikacja nie zamula. → test w Task 6 (limit 150 przy 400 zaległych) i Task 4 (10 dni przerwy z 2 zamrożeniami).
3. **Ta sama karta oceniona offline na dwóch telefonach** — po sync wygrywa nowszy `updatedAt`, obie recenzje zostają (bez duplikatów). → test w Task 12 (`mergeCards` + idempotentne `pushReviews`).
4. **Wpisywanie na telefonie bez umlautów / z autokorektą** — wielka litera na początku, spacja na końcu, „ae” zamiast „ä”, „ss” zamiast „ß” są poprawne. → test w Task 5.
5. **Urządzenie bez niemieckiego głosu (część Androidów, iOS bez pobranego głosu)** — brak błędu, przycisk audio ukryty. → test w Task 8 (`hasGermanVoice` z pustą listą głosów).

  ```
  days = od najwcześniejszego dnia w activity do dnia przed `today`, kolejno
  streak = 0; freezes = 0
  dla każdego dnia d:
    jeśli isGoalMet(d): streak += 1; jeśli streak % 7 == 0: freezes = min(2, freezes + 1)
    inaczej jeśli streak > 0 i freezes > 0: freezes -= 1; frozenDays.push(d)   // streak bez zmian
    inaczej: streak = 0
  todayMet = isGoalMet(today); current = streak + (todayMet ? 1 : 0)
  (jeśli todayMet i (streak+1) % 7 == 0 → freezes = min(2, freezes+1))
  ```
